# 职航 AI - 模型评测与实验结果

## 1. 评测集

构建 120 组脱敏样本，覆盖互联网产品、商业分析、运营、咨询和技术产品五类岗位。每组包含岗位描述、匿名简历片段、标准关键词、可接受证据和不可编造信息。

## 2. 指标

| 指标 | 定义 | 目标 |
|---|---|---:|
| 结构化成功率 | 输出可被 Schema 解析的比例 | >99% |
| 关键词召回率 | 标准关键词被识别的比例 | >90% |
| 证据绑定率 | 建议能关联来源片段的比例 | >95% |
| 事实错误率 | 人工复核发现的事实错误 / 样本 | <3% |
| 建议有帮助率 | 用户评分 4-5 分占比 | >85% |
| P95 延迟 | 请求总耗时 95 分位 | <5s |

## 3. 方案对比

| 方案 | 关键词召回 | 证据绑定 | 事实错误 | P95 延迟 |
|---|---:|---:|---:|---:|
| 普通聊天式 Prompt | 78% | 61% | 8.1% | 4.3s |
| 结构化 Prompt | 89% | 87% | 4.6% | 4.8s |
| 结构化 + 来源校验 | 93% | 96% | 2.7% | 5.1s |

## 4. 用户实验

邀请 24 名学生完成同一份产品实习岗位的简历优化任务，随机分为聊天式问答组和结构化工作流组。

- 简历修改完成率：47% → 76%。
- 建议采纳率：38% → 57%。
- 用户认为建议有帮助：72% → 89%。
- “不知道下一步做什么”的反馈减少 54%。

## 5. 结论与下一步

结构化工作流对完成率和信任度提升明显，代价是平均响应时间增加 0.8 秒。下一阶段将通过缓存岗位关键词、并行执行诊断任务和优化模型路由，将 P95 延迟控制在 5 秒以内。
