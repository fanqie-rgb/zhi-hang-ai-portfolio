# AI 求职反馈助手产品设计

`AI 产品 / 大模型 / 工作流`

把“让 AI 改简历”变成可解释、可确认、可复盘的求职反馈工作流。

## 用户场景

用户准备投递一个产品实习岗位，上传简历后得到一段泛泛的评价：“建议突出项目成果”。用户不知道该改哪一段，也无法判断建议是否真的符合岗位要求。第二次打开产品时，之前的修改意见也没有被沉淀。

## 需求列表

P0｜岗位解析：提取岗位职责、能力关键词和优先级。
P0｜简历诊断：按岗位要求标注缺失、弱相关和可强化内容。
P0｜修改对比：展示原文、建议版本和修改理由。
P1｜追问式面试：根据项目经历生成逐级追问。
P1｜复盘记录：保存用户确认过的修改和待补充证据。
