# AI 求职反馈助手产品设计 - PRD

### 1. 目标
让用户在一次使用中完成“理解岗位 → 找到简历问题 → 修改一段经历 → 获得面试追问”，并能解释每条建议的依据。

### 2. AI 工作流
岗位文本解析 → 关键词与能力分层 → 简历片段匹配 → 生成建议 → 用户确认 → 保存版本。

### 3. 输出约束
- 每条建议必须关联岗位原文或用户简历片段。
- 禁止补造用户未提供的数字、公司或项目结果。
- 对不确定信息标记“需要补充”，而不是直接生成。
- 建议必须提供“为什么改”和“改完解决什么问题”。

### 4. 验收标准
- 用户能看到岗位关键词及其来源。
- 每条改写建议可展开查看依据。
- 用户可接受、拒绝或手动编辑建议。
- AI 生成内容与用户原始事实保持一致。
