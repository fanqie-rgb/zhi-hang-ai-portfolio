# 校园活动平台用户增长与转化优化

`增长 / 漏斗 / 留存`

从“活动曝光”推进到“有效参与”，优化发现、报名、到场和复访全链路。

## 用户场景

用户在首页看到一个感兴趣的活动，但详情页缺少同校参与人数、活动难度和剩余名额等信息。用户犹豫后离开；即使报名成功，也容易因为忘记时间或临时安排冲突而缺席。

## 需求列表

P0｜活动推荐：基于兴趣标签、同校热度和时间可用性排序。
P0｜详情页决策信息：展示参与人数、剩余名额、活动难度和往期评价。
P0｜一键报名：减少重复填写和确认步骤。
P1｜日历同步：报名成功后同步到系统日历。
P1｜参与后评价：记录活动体验，为下次推荐和留存提供依据。
