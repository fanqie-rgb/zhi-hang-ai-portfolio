# 校园二手交易平台搜索与推荐优化 - PRD

### 1. 目标
将“搜索后点击详情页”的比例从 42% 提升至 52% 以上，并缩短用户找到有效商品的时间。

### 2. 核心流程
输入关键词 → 联想补全 → 筛选条件 → 结果排序 → 查看详情 → 联系卖家。

### 3. 关键规则
- 关键词召回：标题、分类、标签、描述字段加权匹配。
- 质量分：标题完整度 20% + 图片数量 20% + 价格有效性 20% + 地理距离 20% + 近期点击 20%。
- 排序保护：低质量商品即使点击高，也不能排在完整商品之前。

### 4. 验收标准
- 输入“显示器”可返回联想词和近 30 天高频规格。
- 筛选条件可组合，刷新后条件不丢失。
- 结果页首屏至少展示商品价格、距离、成色和发布时间。
- 埋点覆盖搜索发起、筛选使用、详情点击、联系卖家四个节点。
