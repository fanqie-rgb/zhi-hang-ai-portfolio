# 校园二手交易平台搜索与推荐优化

`搜索 / 推荐 / 转化`

让用户更快判断“这个结果值不值得点”，缩短从搜索到交易的路径。

## 用户场景

用户带着明确目标进入平台：想在一周内找到一台价格合适、距离较近的二手显示器。当前搜索结果混杂，商品标题不规范，关键信息藏在描述里。用户需要反复翻页、私聊确认，最终因为信息成本过高而放弃。

## 需求列表

P0｜搜索联想：根据校园内高频搜索词补全关键词，减少无效检索。
P0｜结构化筛选：支持价格、距离、成色、发布时间和交易方式筛选。
P0｜结果排序：综合关键词相关性、商品完整度、距离和近期热度排序。
P1｜商品质量提示：对缺少图片、价格或交易地点的商品给出补充提示。
P1｜相似商品推荐：在详情页提供同校、同价位的替代商品。
